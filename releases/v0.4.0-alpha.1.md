First alpha release of the Ubuntu desktop app and its packaging workflow.

### Changes

- Ubuntu-style desktop UI with extraction controls inside Select files.
- Configurable concurrent extraction: 1–12 background tabs, default 3.
- One organized load → select/extract → copy flow, with stronger contrast and clear button states.
- Copy all links or selected completed rows; select unfinished files for retries.
- Stop preserves completed links and closes the extraction browser.
- The entire extraction browser, including the information tab, closes after each batch.
- Page redirects and verification transitions no longer immediately fail extraction.
- Uses installed Chrome/Chromium, Edge, Brave, or Firefox. No browser engine is bundled or downloaded.

### Downloads

- **Ubuntu/Debian x86-64:** download the `.deb`, then run `sudo apt install ./fitgirl-ff-link-extractor_0.4.0~alpha.1_amd64.deb`.
- **Windows x86-64:** download and run the `.exe`.
- **SHA256SUMS:** checksums for both installers.

The Ubuntu package is built on Ubuntu 22.04. Browser automation may download a matching driver on first use. Verification can require interaction in the browser.

This is an **alpha prerelease**, intended for testing and feedback. Chrome on Ubuntu has runtime coverage; other browser and distribution combinations, and the Windows UI, still need wider testing.
